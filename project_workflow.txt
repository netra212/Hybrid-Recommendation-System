# Metrics to Evaluate. 
- Precision - Accuracy of Recommendation.
    - 3 recommendation -> relevant.
Precision@3 = No. of relevant recommendation / No. of top_k recommendation
    - tells the quality of the predictions.
Precision = TP/TP+FP

- Recall
    - 10 Relevant Recommmender. 
    Recall = No. of Recommendation in top_k / No. of all relevant Recommendation
    Recall@10 = 7/10
    Recall = TP / (TP + TN)

# Model Based Recommender Systems. 
- SVD Factorization.
- Build Latent Features -> Hidden features about our tracks. 
- A = U np.sum V^T 
where, U -> tells the trackID latent features. 
       V -> userID latent features. 
       np.sum -> Diagonal matrix tells the relevant matrix. 

- Regression Metrics like: MAE, MSE, RMSE are used in this model based recommender systems. 
- Boosting algorithms like xgboost, lightGBM can be used for this case. 

- To implement SVD Factorization, surprise & recsys python package can be used.
